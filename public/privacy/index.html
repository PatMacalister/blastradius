Privacy

This site collects nothing. The tool it describes uploads nothing. Both statements are short because they are complete.

This website

Static pages only. No analytics, no tracking pixels, no cookies, no embedded third-party scripts, no fonts loaded from anyone else's server — the typefaces are served from this domain. There are no forms and no accounts, so there is nothing to submit and nothing stored about you.

The web server keeps ordinary access logs (IP address, timestamp, requested path, user agent) for operational and security purposes. These are not analysed for behaviour, not linked to any identity, and not shared. [CONFIRM RETENTION PERIOD BEFORE LAUNCH]

The BlastRadius tool

The command-line tool has no telemetry of any kind. It never reports what it finds to anyone, including us — there is no server to report to.

Discovery runs entirely on your machine and is offline. When you pass --resolve, the tool contacts the provider that issued each credential — GitHub, Stripe, Railway, Supabase, Vercel or Cloudflare — and nobody else. Each provider module declares the hosts it may contact and a guard blocks every other destination, so a credential cannot be sent somewhere unexpected even by a faulty or malicious module.

Credentials are never written to disk by the tool and never appear in its output; everything user-facing is fingerprinted, and error messages are scrubbed.

Your rights

Under the GDPR you may request access to, correction of, or erasure of personal data held about you. In practice the only such data is the access log described above. Contact details are in the imprint.
